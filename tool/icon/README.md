# Scry icon

`scry-icon.svg` is the source. It is generated by `scry_icon.py` (seed 11):
a sphere painted in separate gold and purple brush strokes, with splatter,
drips and two painted sparkles, on white.

    python tool/icon/scry_icon.py tool/icon/scry-icon.svg 11
    python tool/icon/render_icons.py tool/icon/scry-icon.svg .

`render_icons.py` uses headless Chrome to write every Android launcher size
(rounded white tile, transparent corners) and every iOS size (full white
square, no transparency, as iOS requires).
