# Scry icon

`scry-icon.svg` is the source. It is generated by `scry_icon.py` (seed 11):
a sphere painted in separate gold and purple brush strokes with rough, torn
edges, heavy splatter, drips and three painted stars (a big gold one in the
middle, a purple one and a small gold one), on white.

    python tool/icon/scry_icon.py tool/icon/scry-icon.svg 11
    python tool/icon/render_icons.py <full path>/tool/icon/scry-icon.svg <full path to repo>

Pass full paths to `render_icons.py`: headless Chrome writes the screenshots
relative to its own folder otherwise. It writes every Android launcher size
(rounded white tile, transparent corners) and every iOS size (full white
square, no transparency, as iOS requires).

The stars are drawn in their own layer with a lighter roughening than the
rest, so they stay crisp. Tome's icon uses the same brush style.
